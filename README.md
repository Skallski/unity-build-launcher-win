# Unity Build Launcher for Windows

A simple PowerShell-based launcher for Unity builds that allows you to configure launch parameters before starting the application.

Currently supported parameters:
- **Display Mode** — Windowed / Fullscreen
- **Screen Width**
- **Screen Height**

## Usage
1. Extract the downloaded `.zip` archive.
2. Double-click **`UnityAppsLauncherStartup.bat`**.
3. Select the Unity build you want to launch.
4. Configure the desired launch parameters.
5. Click **Launch**.

## Important!
Both launcher files — **`UnityAppsLauncherStartup.bat`** and the **`UnityAppsLauncher.ps1`** — must be located in the same directory for the launcher to work correctly.
